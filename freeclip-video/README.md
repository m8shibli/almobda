# مونتاج فيديو HUAWEI FreeClip 2S

فيديو عمودي 1080×1920، 30fps، ~65 ثانية — موشن جرافيك بطابع فاخر (أسود زجاجي + ذهبي شامبين).

- `edit.html` — كل الجرافيكس متزامنة مع الكلام (`render(t)` حتمية لكل إطار) + جدول المؤثرات `CUES`.
  - اسم السماعة بالإنجليزي (HUAWEI FreeClip 2 / Special Edition / FreeClip 2S) بظهور حرف بحرف.
  - عدّاد 8,000,000+ مبيعات، وزن 5.1g، تحديد الصوت التلقائي، Reverse Sound Field، 3 مايكات، موجة ضوضاء تتحول لصوت نقي.
  - أجهزة: iPhone / Android / Tablet / Computer مرسومة بالكامل CSS، واتصال بجهازين.
  - السعر 69.900 ر.ع بعدّاد ذهبي وانفجار جزيئات + هدية بقيمة 9.900 ر.ع، وخاتمة.
- `audio.py` — يمزج الصوت المنقّى + المؤثرات + **أصوات زحمة ناس وشارع** (مولّدة برمجياً، أقل من الصوت بـ 12dB) عند ذكر عزل الضوضاء + موسيقى خلفية تنخفض وقت الكلام.
- `sfx.py` — مكتبة المؤثرات الصوتية (من مشروع sana-video).
- `render.js` — تصوير الإطارات عبر Playwright وترميزها بـ ffmpeg.
- `build.sh <source.mov>` — يبني كل شيء ويخرج `output/freeclip-2s-edit.mp4`.

المتطلبات: ffmpeg، Node + Playwright، Python + numpy + scipy.
