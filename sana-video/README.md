# فيديو ترويجي: سنا — وكيل ذكاء اصطناعي عُماني

فيديو عمودي (1080×1920، 30fps، ~58 ثانية) بخط **SF Mada Bold** مع أيقونات SVG ومؤثرات صوتية مولّدة برمجياً.

- `scene.html` — المشاهد والأيقونات والحركة (دالة `render(t)` حتمية لكل إطار) + جدول المؤثرات الصوتية `CUES`.
- `render.js` — يصوّر الإطارات عبر Playwright ويرمّزها بـ ffmpeg.
- `sfx.py` — يولّد المؤثرات (whoosh / pop / impact / boom / typing / coins / bell …) وموسيقى خلفية خفيفة.
- `build.sh` — يبني كل شيء ويخرج `output/sana-promo.mp4`.
